# Promofilm for Techauge – Tilbud og prosjekt

## Mål

En reklamefilm i Apple-stil som får andre maskin- og anleggsentreprenører til å
ville bruke systemet. Den skal se ut som et dyrt animasjonsprodukt og formidle
tydelig, også uten lyd.

## Beslutninger

| Spørsmål        | Valg                                                                                           |
| --------------- | ---------------------------------------------------------------------------------------------- |
| Målgruppe       | Andre entreprenører (Techauge som produkt)                                                     |
| Kanaler         | Nettside/YouTube, LinkedIn/Facebook, Reels/TikTok/Shorts og messe                              |
| Lyd             | Musikk og tekst på skjermen, ingen stemme. Lydeffekter laget selv                             |
| Musikk          | «Creative Technology Showreel» (Pumpupthemind, Pixabay-lisens, ikke i Content ID)               |
| Vinkel          | Hele flyten: ett oppdrag følges fra tilbud til siste krone                                      |
| Metode          | Remotion, med appens skjermer gjenskapt i React og oppdiktede data                              |
| Stil            | Mørk og filmatisk: svart scene, hvit Inter-tekst, rødt fra logoen som aksent                    |

Stilen og resten av detaljene ble overlatt til Claude («ta alt du tror og lag
filmen»).

## Manus (hovedfilmen, ~87 sek)

1. «Hele dagen i maskina.» / «Hele kvelden med papirarbeid.»
2. Kaos: dokumenter, regneark, e-post, SMS og lapper hoper seg opp mens klokka
   går mot midnatt, og suges inn i ett rødt punkt.
3. Punktet blir logoen på droppet i musikken. «Tilbud og prosjekt.»
4. Dashbordet stiger fram: «Alt om jobben, samlet på ett sted.»
5. Tilbud: «Et ryddig tilbud på noen minutter.» Linjene fylles, og PDF-en glir
   ut: «Ferdig PDF med din egen logo.»
6. Signering: «Kunden signerer rett på mobilen.»
7. Varsel: «Du får beskjed med en gang.»
8. Endring: «Tirsdag kl. 09.12 – Traff fjell i grøfta.» → «Kunden signerer
   endringen før du graver videre.»
9. Fremdriftsplan: «Fremdriftsplanen er klar til byggemøtet.»
10. Ordre: «Du ser hva som er fakturert, og hva som gjenstår.»
11. Pausen i musikken: «Taper du anbud uten å vite hvorfor?» → anbud: «Se
    hvordan konkurrentene priser seg.» / «Hentet rett fra anbudsprotokollene.»
12. Mobil: «Hele oversikten, også på mobilen.»
13. «Mindre tid på kontoret. Mer tid i maskina.» → logo og techauge.no

Første utkast brukte engelske reklamegrep oversatt til norsk («Du flytter
fjell», «Én ting til», «Mindre kontor. Mer maskin.»). Brukeren syntes det
virket oversatt, så teksten ble skrevet om til hele, vanlige norske setninger —
slik folk i bransjen snakker. Åpningen og slagordet svarer nå på hverandre:
kvelden går med til papirarbeid; løsningen gir mer tid i maskina.

Kortversjonene (33 og 30 sek) bruker de samme scenene raskere, med slagord og
logo på sluttslaget i sporet.

## Avgrensninger

- Ingen påstander appen ikke dekker: den registrerer fakturering, men lager ikke
  fakturaen, og mobilvisningen er en oversikt, ikke hele appen.
- Ingen ekte data eller firmanavn. Oppdiktede navn er sjekket mot
  Brønnøysundregistrene.
- Ingen Apple-fonter eller -maskinvare: Inter i stedet for SF Pro, og en nøytral
  telefon uten modellkjennetegn.
- Musikkfila ligger ikke i git (lisensen tillater ikke å spre den videre alene).
